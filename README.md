# 農民曆 · nongminli.tw

[nongminli.tw](https://nongminli.tw/) 是一本放在網路上的台灣農民曆。打開首頁，先看到今天的西元、民國、農曆三個日期，接著是七天內的國定假日、干支、建除與沖煞，再往下是今天的宜忌與吉時。農曆與節氣依中央氣象署資料，國定假日依行政院人事行政總處的辦公日曆表，宜忌屬傳統通書記載，每一條都附出典。

本站只適用於台灣：日期與時辰以台灣時間計，假期與習俗以台灣為準。全站正體中文，不做命理與求籤。

這個儲存庫提供網站介紹、訂閱教學與問題回報入口，不包含網站完整原始碼。

## 訂閱台灣國定假日

把假日放進平常使用的行事曆，不必每年重新匯入一份檔案。免費公開訂閱，目前收錄 **2026、2027 年**的國定假日、補假與補班事件，依行政院人事行政總處「行政機關辦公日曆表」整理；一般週末不逐日建立事件。民間企業與學校仍以各單位公告為準。

固定訂閱地址：

```text
https://nongminli.tw/ical/subscribe/holidays.ics
```

- **Google 日曆**：用電腦版開啟「其他日曆」旁的「＋」→「加入日曆網址」，貼上上述地址。
- **Apple 行事曆**：在「加入訂閱行事曆」貼上上述地址，再確認加入。
- **Outlook 網頁版**：選「新增行事曆」→「從網路訂閱」，貼上上述地址。

[完整訂閱教學、更新範圍與常見問題](docs/calendar-subscription.md) · [線上假期頁的訂閱入口](https://nongminli.tw/holidays/2027#subscribe)

新年度經本站核對並發布後才加入，**2028 年尚未收錄**。日曆服務自行安排重新整理時間，不保證即時更新或通知。只需要單次匯入，可下載 [2026 年 .ics](https://nongminli.tw/ical/holidays/2026.ics) 或 [2027 年 .ics](https://nongminli.tw/ical/holidays/2027.ics)；匯入檔案與持續訂閱不同，請避免重複加入同一組假日。

## 依據

### 農曆、節氣與宜忌分開處理

| 欄位 | 資料與計算方式 | 使用邊界 |
|---|---|---|
| 國曆、農曆、閏月 | 農曆資料由 `lunar-javascript` 產生，再與中央氣象署日曆資料表核對；已收錄官方全年表的 2026、2027 年以官方值為準 | 以台灣時間換日；不把演算法推算稱為官方公布 |
| 二十四節氣、朔望兩弦 | 已有官方表的時刻採中央氣象署公布值；尚未公布的部分才採天文推算 | 節氣按太陽視黃經每 15 度的交點推算，時刻與日期要一起核對 |
| 國定假日、補假、補班 | [行政機關辦公日曆表（資料集 14718）](https://data.gov.tw/dataset/14718) | 不預估尚未公布年度；不代表所有企業、學校的放假安排 |
| 干支、建除與沖煞 | 《欽定協紀辨方書》等傳統規則，逐欄附來源與取法 | 各欄位的換年、換月界線不一定相同 |
| 宜忌、吉時 | 傳統通書記載與本站採用的取法，詳見頁面註腳 | 屬民俗參考，不是天文事實，也不保證個人結果 |

### 怎麼核對

網站維護時，農曆逐日對照已收錄的中央氣象署年表；節氣與朔望檢查日期、時刻和來源標記。官方資料與推算結果分開比較，頁面有官方值時使用官方值。日曆訂閱另檢查事件日期、穩定識別碼與更正版本。

你也可以不用程式，核對兩個例子：

1. 打開 [2026 年 1 月 1 日](https://nongminli.tw/nongminli/2026-01-01)，比對[中央氣象署日曆資料表](https://www.cwa.gov.tw/V8/C/D/calendar_data.html)的國曆、農曆欄；假日名稱另對照辦公日曆表，不用宜忌判斷是否放假。
2. 打開 [2027 假期頁](https://nongminli.tw/holidays/2027)，將任一補假日與訂閱中的同一天比較。訂閱用全天事件表示日期，沒有把午夜當成活動開始時間。

發現差異時，請提供「頁面網址、日期、欄位、你核對的來源網址或版本」；個人生日、姓名等私人資料不用貼在公開 issue。
