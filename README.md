# 農民曆 · nongminli.tw

[nongminli.tw](https://nongminli.tw/) 是一本放在網路上的台灣農民曆。打開首頁，先看到今天的西元、民國、農曆三個日期，接著是七天內的國定假日、干支、建除與沖煞，再往下是今天的宜忌與吉時。農曆與節氣依中央氣象署資料，國定假日依行政院人事行政總處的辦公日曆表，宜忌屬傳統通書記載，每一條都附出典。

本站只適用於台灣：日期與時辰以台灣時間計，假期與習俗以台灣為準。全站正體中文，不做命理與求籤。

## 從這裡開始

- [今日農民曆](https://nongminli.tw/)：今天的西元、民國、農曆，七日週帶、宜忌與吉時
- [2027 農民曆（民國116年）](https://nongminli.tw/nongminli/2027)：全年月曆縮覽、國定假日、二十四節氣與歲次，另有可列印版本
- [擇日：選一件事查好日子](https://nongminli.tw/gooddays)：結婚、入厝搬家、開工、安床、動土、交車等事項，逐日列出宜忌與沖煞
- [安太歲](https://nongminli.tw/taisui)：哪些生肖犯太歲、什麼時候安、要準備什麼，以及各區廟方的官方入口
- [2027 國定假日・行事曆](https://nongminli.tw/holidays/2027)：國定假日、補假、補班與連假，可加入行事曆
